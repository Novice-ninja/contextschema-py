# Code Of Conduct

ContextSchema is intended to be a focused technical project. Participation
should stay respectful, direct, and useful.

## Expected Behavior

- Discuss ideas and code on their merits.
- Assume good intent, but ask for evidence when claims are unclear.
- Keep criticism specific and actionable.
- Respect differing levels of experience.
- Avoid harassment, insults, threats, or sustained disruptive behavior.

## Unacceptable Behavior

- Personal attacks or discriminatory language.
- Public or private harassment.
- Publishing private information without permission.
- Repeated off-topic disruption after maintainers ask for focus.

## Enforcement

Maintainers may edit, hide, or remove comments; close issues; decline pull
requests; or block participants when behavior makes productive collaboration
harder.

If you see a problem, open an issue only if public discussion is appropriate.
For private concerns, contact a maintainer through the GitHub account listed on
the repository.
